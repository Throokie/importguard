# Security and financial-data handling

ImportGuard is intended to run on your own machine, bound to `127.0.0.1`. Do not expose it through a public interface, reverse proxy or shared hosted service. It has no multi-user authentication system.

Please do not put real bank statements, credentials, cookies, account numbers or personal data into issues, pull requests, logs or screenshots. Provide the smallest synthetic reproduction possible. For a suspected vulnerability, use GitHub private vulnerability reporting if it is enabled; otherwise start with a sanitized issue that does not include exploit details or sensitive data, and ask for a private reporting route.

Only the latest published release is currently maintained on a best-effort basis. There is no promised response time or independent audit claim. Keep your original CSVs and ledger backups, and verify destination imports separately.
