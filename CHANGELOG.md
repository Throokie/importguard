# Changelog

## 0.3.0

- English and Simplified Chinese interface, browser-language defaults and optional saved language preference.
- Switch language without clearing files, mappings, filters or row decisions.
- Localized evidence, errors, nested validation details, export README and warnings; original transaction data and import CSV bytes are preserved.
- Structured message codes/parameters, explicit per-request language isolation and CLI `--language`.
- English/Chinese screenshots, 73 Python checks and a 23-check local browser scenario. CI results are recorded per commit on GitHub.
- Matching/account/currency rules and known Actual 26.10.0 limitations are unchanged. The approved v0.2 GIF is retained as a historical workflow demo.
